# DICE ROLLER APP
- This is a simple app made using Jetpack Compose. It shows a single dice image. The dice image changes every time user clicks on the "Roll" button.

## What have I learned:
- How to create a button in Jetpack Compose.
- Use of Spacer composable in Jetpack compose.
- How to make a mutable state object using mutableStateOff( variable value ).
- Using remember to protect value of a variable during recomposition.

## How to opent the app:
- Clone the files in your system. Open using Android Studio.
